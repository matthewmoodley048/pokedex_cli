# Pokedex CLI

A simple command-line Pokedex written in Go. It runs an interactive prompt (`Pokedex >`) where you type commands to look up Pokémon data and explore regions.
Some of the features include a info look up of pokemon you have caught from data fetched from https://pokeapi.co/ using http requests.

## Run

Requires [Go](https://go.dev/doc/install).

```
git clone https://github.com/matthewmoodley048/pokedex_cli.git
cd pokedex_cli
go run .
```

Type `help` to see the available commands.
